# Beatrice Headline Trial

Beatrice Headline is a commercial typeface (Displaay) and can't be redistributed here.
Place your licensed / trial files in this folder with these names:

- BeatriceHeadlineTrial-Light.woff2   (300)
- BeatriceHeadlineTrial-Regular.woff2 (400)

Only `.otf` files? Convert with `npx fonttools ttLib.woff2 compress <file>.otf`
or any woff2 converter. The @font-face rules live in `src/styles/fonts.css`.
