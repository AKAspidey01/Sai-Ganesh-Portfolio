# Beatrice Headline Trial

Beatrice Headline is a commercial typeface by Displaay. The files here are the
**trial** versions, used for the KPI numbers in the About section:

- BeatriceHeadlineTrial-Light.otf   (300)
- BeatriceHeadlineTrial-Regular.otf (400)

The @font-face rules live in `src/styles/fonts.css`. Before using the site
commercially, buy a web licence from Displaay and swap in the licensed files
(ideally as `.woff2`, then change `format('opentype')` to `format('woff2')`).
