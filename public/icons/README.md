# Tool logos

The Skills marquee renders the logo for each tool from `src/data/portfolio.ts`
(`skills[].logo`). Drop the official SVGs from each brand's press kit here,
e.g. `figma.svg`, `react.svg`, `vscode.svg`, `framer.svg`, then set
`logo: '/icons/figma.svg'`. Tools without a logo show a monogram tile.
